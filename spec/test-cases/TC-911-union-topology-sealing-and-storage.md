# TC-911: Union topology precedes atomic verified sealing

## Description

Exercise the shared registry's actual resolved and sealed stages, preserving
the distinction between supplied fixture identities and canonical producer
verification. Extend TC-907's protected Union portion at the production
reservation seam; do not substitute a budget denial for an allocation denial.

## Test Procedure

1. Read names, declared order and position types from unbound topology. Check
   named escaping cycles, nonescaping refusal loci and unused IEEE alternatives.
   Verify that unsealed lookup, runtime construction and carrier admission refuse.
2. Seal complete ordered producer-verified bindings and inspect both inverse
   joins and the original descriptor handle. Mutate count, order, identifier,
   declaration, member uniqueness, resealing and final-key collisions separately;
   assert the exact existing typed refusal and unchanged logical environment.
3. Deny actual Union registry, member-type and recursion traversal reservations
   independently. Deny each of the member-index, forward-join and inverse-join
   destinations during sealing. Assert the measured request's native unit,
   unchanged descriptors/indexes/joins, and complete deterministic retry using
   the same caller budget. Deny a refusal-name byte reservation separately.
4. Retain all existing 5,000-member/1,000-Option and 10,000-value small-stack
   tests and independently decomposed N/N-1 counters. Retain released capacity,
   native-leaf, quantity, typed-cause and both Record/Tuple prior-stop controls.

only after atomic exact sealing. Storage denial retains the actual request,
capacity remains distinct, and neither is fabricated as an input or work failure.
