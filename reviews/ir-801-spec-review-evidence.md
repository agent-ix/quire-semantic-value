| FND-001 | medium | AC-10 is verified by Test but asserts 'No field, population member list, path, clock or global is consulted'. In a no_std crate with no clock, filesystem or global hook to instrument, a test cannot observe non-access to a path, clock or global, so this clause passes for any implementation. Move it to Inspection (or Analysis of the read functions' signatures and bodies) and keep Test for repeat equality, zero allocations and clone equality. | spec/functional/FR-119-admit-and-read-relationship-extents.md:187; spec/test-cases/TC-919-relationship-extents-admit-and-read.md:86-89 |
| FND-002 | medium | AC-13's 'object type unknown to the environment' case cannot detect a missing explicit membership check. from_enumerator refuses an unknown covered type, so every covered type in a manifest is a member; conforms(unknown, member) is false because the keys differ and is_ancestor returns false for an unknown sub. An implementation that skips the membership check therefore still returns Undecidable. The check is observable only if the manifest was built against a different TypeEnvironment that knows the type; state that setup (or drop the claim). | spec/functional/FR-119-admit-and-read-relationship-extents.md:128-129; spec/functional/FR-119-admit-and-read-relationship-extents.md:190; src/declaration.rs:2446; src/declaration.rs:4328 |

Omitting the membership check yields the same EndTypeMismatch. The clause is harmless but adds no evidence; AC-1 is where the equal-key trap is falsifiable. | spec/functional/FR-119-admit-and-read-relationship-extents.md:100-104; spec/functional/FR-119-admit-and-read-relationship-extents.md:181; src/declaration.rs:4328 |

## Verdict

Changes requested. Most ACs are concrete, single-fault and falsifiable. Six cannot produce discriminating evidence as written: AC-10's non-access claims are not observable by a test; the unknown-type cases of AC-13 and AC-4 cannot detect a missing membership check; AC-12 states only a necessary condition for Dangling; AC-18 leaves the source_rows value unpinned; and two AC clauses (AC-2's 'known non-navigation key', AC-7's 'None is inferred from another') add no checkable evidence.
